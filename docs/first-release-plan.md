# 首个正式版本目标与验收

目标建立日期：2026-10-15。用户已授权将 Kingston DataTraveler 3.0、原卷名 CARLINK、约 15.47 GB 的 U 盘作为专用测试介质，包括清空、格式化、读写与推出；该授权不覆盖其他磁盘。

## 目标

完成可安装、可验证的盘渡首个正式版本：在默认系统安全设置下，通过原生文件系统扩展提供外置 NTFS 的实际 Finder 读写，完成真实介质的数据一致性与安全推出验证，再发布 GitHub 正式版本及可复现源码。

当前 `0.2.0-dev` 只有磁盘控制层，未集成 NTFS 写入。不会通过改版本号或缩减“真正可用”的含义来抵扣核心功能。

## 工作顺序

1. 固定真实测试盘身份，保存系统扫描和能力基线；建立在专有目录内进行文件操作、哈希和重新挂载复查的实盘验证工具。
2. 核实原生 FSKit 扩展构建、签名、启用和受控资源访问；审查可复用 NTFS 适配代码的固定版本及许可，独立保留版权和源代码。
3. 完成只读挂载、健康检查、受控读写、同步与卸载；先用一次性镜像，再用指定 U 盘。不得使用关闭 SIP 或降低启动安全策略的方式通过验证。
4. 打通自动读写设置、单盘例外、Finder 操作和错误反馈；只有真实可用的能力可以显示为启用。
5. 完成真实文件语义、意外状态、忙盘、重新挂载与数据持久化验证。完成 Windows 侧交叉读取和一致性检查，记录验证范围。
6. 完成签名、公证、安装与卸载、版本说明、许可清单、校验值和构建复现；检查全部发布门槛后创建首个正式 GitHub Release。

## 测试盘边界

2026-10-15 基线为 `disk8` / `disk8s1`，FAT32，卷名 CARLINK。BSD 设备号会变化，不能直接用此记录作为以后操作的授权身份。操作工具必须重新查询并验证当前设备；格式化后重新建立身份记录。运行报告、原始身份信息和测试数据存放于忽略的 `artifacts/`，不提交个人磁盘信息。

## FAT32 实盘基线结果

指定 U 盘的专有测试目录中完成 71 个文件操作，包括 128 MiB 测试文件、64 个小文件、Unicode 文件名、8 层目录、原子替换、重命名、随机写、截断和删除。首次 SHA-256 校验通过，正常卸载并重新挂载后再次校验通过。报告位于本地 `artifacts/release-qualification-2026-10-15/fat32-roundtrip.json`。这是系统 FAT32 文件系统的实盘基线，不是 DiskFerry NTFS 写入证据。

## 2026-10-16 开发检查点

独立实验 FSKit 扩展使用固定 NTFS-3G 核心与具有来源记录的 GPL 适配代码，默认只读且没有自动介质匹配。新建 Xcode 工程供配置真实 Apple Team；本地实验脚本和无签名 Xcode 工程均编译通过，默认宿主 Universal 2 构建通过。

首轮检查点有 67 项自动检查通过：37 项 Swift 测试（包含真实系统只读镜像的身份核验和正常推出）、12 项 NTFS 桥接镜像测试、9 项 FSKit 属性与资源几何校验、9 项实盘工具边界测试。修复只读卷返回创建成功、未实现属性修改静默成功、资源几何转换与分配缺少边界、卸载未关闭引擎等问题。U 盘 71 文件再次校验通过。测试命令见 [FSKit 开发说明](fskit-development.md)。

后续故障验证复现了两项实际缺陷：写入失败后仍能继续创建文件，写入进程被强制结束后仍将卷判断为干净。现已增加会话故障记忆、写入前持久化脏标记、完整结束后清除本次标记及 Windows 日志只读检查。NTFS 桥接测试扩充至 21 项且全部通过，包含实际 SIGKILL 子进程、读写故障、同步恢复、退出失败、正常再次挂载及无效 Windows 日志；总计已有 76 项自动检查通过。实验扩展与无签名 Xcode 构建也通过。

这些是开发证据。尚未打通真实 FSKit 资源与 Finder 挂载，也未集成自动读写/单盘策略向扩展的受控传递。真实资源同步和硬件断电保护、实盘异常拔出与进程中断、重命名替换、打开后删除、创建属性及并发文件语义仍需系统验证和完善。当前不启用扩展写入，不发布正式安装包。

独立系统回读检查已通过：使用 macOS 自带只读 NTFS 驱动挂载桥接引擎生成的普通镜像，逐字节核对中文、空格、重音与 emoji 文件名、随机修改后截断的内容、重命名和空文件，正常卸载后镜像哈希未变。软件自身的系统镜像测试也对该输出通过真实识别、连接身份核验与非强制推出。这不代表 FSKit 已可写或 Windows 互操作已通过。

进一步复现了隐藏元数据仍可按路径修改的缺陷（修改 `$MFT` 时间返回成功）。现已统一限制公共路径入口，阻止对内部元数据及 `$Extend` 的访问与修改，保留根目录属性、普通 `$` 前缀文件和 SYSTEM 标志的符号链接。桥接测试扩展至 26 项且通过，总计 81 项自动检查；静态分析与本机实验扩展构建通过。大小写匹配、只改大小写的重命名及以上其他文件语义仍待完善和系统验收。

本机目前没有可用的 Apple Development / Developer ID 身份，仅有其他项目的本地自签名证书。签名配置、系统接纳与公证需要用户自己的 Apple Developer Team；Windows 交叉验证环境和真实下次登录验证也尚未就绪。所有未通过的发布门槛保持开放。
